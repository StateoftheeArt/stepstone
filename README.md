# Stepstone

Practical learning with worked examples, small activities, a personal Pip companion and private mentor feedback.

Stepstone is an early project for learners building confidence with everyday skills and the people supporting them. It includes 144 active modules across Money & math, Reading & writing, Science, Life skills, Digital skills and Work & jobs. Lessons and interface code are available for review and adaptation under the MIT license. Bundled third-party assets keep their own terms: see [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).

Current source: interface **121**, server **41**. This is an early supervised pilot. Money examples use original Stepstone value diagrams; the Museum is linked separately for recognising real Canadian cash. Publishing the source does not create a shared online service.

## Try it in your browser

[Try the Stepstone browser demo](https://try-stepstone.corbett.chatgpt.site).

No download or sign-in is needed. Explore all 144 modules, practise with worked examples and checks, customise Pip, and try a fictional mentor review. Your practice stays on that browser. Use the full application below for real learner invitations and private shared feedback.

## Run locally

Install Python 3.10 or newer. In this folder run:

```sh
python -B server.py --desktop --host 127.0.0.1 --port 8090
```

Open `http://localhost:8090/`. Core lessons, accounts and reports use Python's standard library; Node and third-party Python packages are not needed to use them. On Windows, `Launch_Stepstone.bat` also finds an installed Python launcher or Python executable.

Choose **I'm mentoring → Create account**, enter your own passphrase and save your private recovery key. Then use **Mentor → Invitations** for one private start link per learner. Returning learners use their existing return link. [Mentor guide](MENTOR_GUIDE.md) · [Learner guide](LEARNER_GUIDE.md).

Localhost works on the computer running the app. For learners on other devices, deploy the Python app with persistent storage behind HTTPS and give them private links from that shared installation. GitHub Pages alone does not provide accounts, saved reports or mentor feedback. [Hosting](HOSTING.md) · [Recovery and operations](OPERATIONS.md).

Each installation has its own records. Learner records, credentials, private invitations and reward details live in `data/`; never commit or publicly upload that directory. The source package contains no learner databases, account records, private links, backups or voice models.

## Run the full app online for free

[Free-host setup](FREE_HOSTING.md) describes a PythonAnywhere Beginner installation with persistent records, separate mentor accounts, invitations and shared feedback. ## What testers can help with

- Learners and mentors: confusing wording, unclear examples, missing instructions and difficulty returning to an activity.
- Educators and literacy volunteers: lesson accuracy, useful practice, accessibility and the way learner explanations are reviewed.
- Developers: local setup, readable controls, account isolation and a straightforward hosted setup.

Report the module title, what you expected and what happened. Use fictional examples and redact names, invitation links, recovery keys and learner answers from public issues. A score is one piece of evidence; mentors should discuss explanations and try a changed example. The app is not an accredited qualification or a validated measure of independent mastery.

Pip customisation and Steps recognise progress. Real gift cards, laptops or subscriptions require a mentor's actual funding and separate review; downloading Stepstone does not provide or guarantee them. [Reward rules](funding/POINTS_AND_REWARDS.md).

Soft narration is optional and needs a separate host runtime. Browser voices are an explicit Reading & comfort option where supported. Voice models and machine-specific configuration are not included. [Read-aloud setup](VOICE.md).

## Development

The shipped lesson catalogue is `public/catalog.json`; check cases are `content/checkpoints.json`. Check cases are kept outside the web static root, but are readable in this open source repository. Assessment depends on human follow-up, not secrecy or proctoring. Some curriculum builder files describe earlier generations; do not regenerate the whole catalogue without reviewing changes to the current lessons.

Original money-value diagrams are generated by `tools/build_teaching_money.py`. After public asset changes, rebuild icons and the offline cache:

```sh
python -B tools/build_assets.py
```

Backend verification uses only the Python standard library:

```sh
python -B -m unittest discover -s tests -p "test_*.py"
```

With Node.js 22 or newer installed, run `node tests/test_content.cjs` and the individual `tests/test_*.mjs` suites. The separate browser audit harnesses and private receipts are outside this source package. [Contributing](CONTRIBUTING.md) · [Verification scope](VERIFICATION.md).
